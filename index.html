Microservices-based payment integration (Stripe)

A two-service flow. The Validation service checks every incoming payment request before the Stripe Provider service is allowed to talk to Stripe.

  • Implemented filter-level HMAC-SHA256 verification from the request data and a shared secret, so unsigned or altered requests are rejected before any business logic runs.
  • Added Spring Validation field checks and duplicate transaction-reference checks to stop bad and repeated payments.
  • Connected the services with REST APIs and Spring RestClient. Applied the circuit breaker pattern and handled failures from the downstream service and the Stripe API.
  • Stored data with Spring Data JPA and MySQL. Used AWS EC2, RDS, Secrets Manager and IAM for deployment and configuration.
